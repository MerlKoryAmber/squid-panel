# ADR 0003 — Два UI политики: эксперт Squid и простой KWTS-стиль

Дата: 2026-08-20, 19:50 МСК.  
Статус: **ПРИНЯТО** (человек, 2026-08-20, 19:49 МСК).  
Дополнение: 2026-08-20, 20:10 МСК — Simple только после явной кнопки «Enable Simple» (человек выбрал в чате).

## Решение

Два представления одних правил, переключатель. Бэкенд и таблицы не дублировать.

**Простой (KWTS-стиль)**

- HTTP rules: «откуда → куда → разрешить/запретить». В этом разделе нет слова ACL, нет чипов имён Squid, нет preview `http_access`.
- Каскад: «кого → в какой канал». Канал = один созданный пир **или** напрямую. Нет раздельных «peer access» и «when to use cascade» в этом виде.
- Списки IP/сайтов/групп живут в существующем разделе (можно подписать «Списки», не обязательно прятать). Слово ACL запрещено в простых HTTP rules и простом каскаде, не обязательно во всём приложении.

**Эксперт**

- Текущие экраны: HTTP Access (мешок ACL + allow/deny), Cascade (пир, `cache_peer_access`, `never_direct` / `always_direct`).

**Данные**

- Те же `http_access_rules`, `cache_peers`, `cache_peer_access_rules`, `never_direct`/`always_direct`.
- Простой HTTP-rule пишет в `acls` имена: «откуда» = типы src / srcdomain / proxy_auth / AD-группы; «куда» = dstdomain / dst / url_regex / файловый список сайтов.
- Простой каскад компилируется: пир X → `cache_peer_access X allow` + deny на других пирах + `never_direct allow`; Direct → `always_direct allow`. Чекбокс «Forbid DIRECT» не отдельный UX — это выбор канала.
- Режим: настройка на пользователя/сессию (`simple` | `expert`), не две схемы БД.
- **Simple выключен**, пока админ не нажмёт Enable Simple (`settings.simple_ui_enabled`). Импорт live conf живёт в Expert. Кнопка не конвертирует CONNECT/порты и не чистит импорт. После включения — переключатель Simple/Expert как раньше.

**Кривые правила (импорт live conf)**

- `CONNECT`, порты, `!Safe_ports`, время, метод — не «откуда/куда». В простом виде: системные/сложные, «открыть в эксперт», не молча портить.
- Отрицание `!acl` в простом UI не рисуем (позже «кроме списка», если понадобится).

Живой `/etc/squid/squid.conf` генератор целиком не переписывает. Каскад пиров по `name=` без изменения смысла.

## Отвергнуто

- Вторые таблицы `*_simple` рядом с Squid-моделью.
- Убрать экспертный UI.
- Показывать слово ACL в простом HTTP rules / простом каскаде.
- Свести каскад только к access одного пира без явного Direct.
- Включать Simple сразу после импорта live conf (обход CONNECT/портов в простом виде).
